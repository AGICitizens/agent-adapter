# 0G

## Use

We deployed a custom escrow contract on 0G Galileo testnet that handles x402-style payment settlement for AI-agent-paid API calls. Every payment in our demo settles on-chain through this contract — the agent calls `pay(nonce, payee)` with native 0G, the contract emits a `Paid` event, and our runtime verifies that event before releasing the upstream API response. Two real on-chain payments in our demo prove the flow works end-to-end on Galileo.
